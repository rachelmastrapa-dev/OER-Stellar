# ADA and WCAG Guidelines for Astronomy OER
Step‑by‑step checklist for creating ADA‑ and WCAG‑compliant OER textbooks. 
## Faculty must ensure that: 
WCAG 2.1 – Success Criterion 1.1.1 (Text Alternatives) is met → All non‑text content must have a text alternative that provides equivalent meaning. 

ADA Title II obligations apply → Public institutions must provide equal access to instructional content for students with disabilities. 
## Identify All Non‑Text Content 
For each chapter, systematically scan for non‑text elements, including: 
- Images (photos, diagrams, illustrations, icons) 
- Charts, graphs, tables, infographics 
- Maps and spatial graphics 
- Embedded media (video thumbnails, audio players) 
- Animated visuals (if used instructional) 
## Informative or Functional Images → Use Alt Text 
Alt text requirements: 
- Short (generally under 125 characters) 
- Identifies the relevant object(s) 
- Reflects what a sighted student gains from the image 
- Embedded directly with the image 

Do not: 
- Start with “image of,” “picture of,” or “graphic of” 
- Repeat caption text word‑for‑word 
## Accessible Descriptions
Complex Visuals → Use Alt Text + Accessible Description 
Use both when the image cannot be understood in one sentence. 

Examples include: 

- Charts 
- Diagrams 
- Images 
- Maps 
- Illustrations 

General Rule of thumb: 
 If understanding the visual takes more than one sentence, add a long description. 
### Create an Effective Accessible Description 
Accessible descriptions should answer four questions: 
- What is shown? 
- What relationships or patterns matter? 
- What labels or text must students know? 
- What is the instructional takeaway? 

What to Include 
- Title of the visual (if present) 
- Scope (what area, system, or process is shown) 
- Key parts, axes, or regions 
- Relationships, trends, or sequences 
- Labels that are instructionally important 
- Conclusions students should draw 

What to Avoid 
- Exhaustive visual detail 
- Stylistic descriptions 
- Conclusions beyond what is in the figure - describe only what is actually present. 
### Address Color and Visual Encoding 
Color is almost always important in astronomy figures: 
- If there is no explanation of the meaning of color, ask the content expert 
- Explicitly describe the meaning of color in text 
- Always describe color in images 
- For false color/composite images, explain how the colors are assigned if available, or include the wavelength of the light. Example: An infrared image of the Crab nebula 

When describing the instructional takeaway, use color when it is relevant. Otherwise, describe what the color represents. Examples: 
- In this globular cluster, the blue stars are larger and bright than the yellow stars. 
- There is more detail in the complex structure in the infrared image of the Crab Nebula compared to the visible image.  
### Handle Images That Contain Text 
If the image includes text students need to know Include verbatim in the accessible description 
Examples: 
- Chart titles, axis labels, data ranges 
- Diagram labels 
- Map legends
