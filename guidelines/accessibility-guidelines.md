# ADA and WCAG Guidelines for Astronomy OER
Step‑by‑step checklist for creating ADA‑ and WCAG‑compliant OER textbooks. 
## Faculty must ensure that: 
WCAG 2.1 – Success Criterion 1.1.1 (Text Alternatives) is met → All non‑text content must have a text alternative that provides equivalent meaning. 

ADA Title II obligations apply → Public institutions must provide equal access to instructional content for students with disabilities. 
## Identify All Non‑Text Content 
For each chapter, systematically scan for non‑text elements, including: 
- Images (photos, diagrams, illustrations, icons) 
- Charts, graphs, tables, infographics 
- Maps and spatial graphics 
- Embedded media (video thumbnails, audio players) 
- Animated visuals (if used instructional) 
## Informative or Functional Images → Use Alt Text 
Alt text requirements: 
- Short (generally under 125 characters) 
- Identifies the relevant object(s) 
- Reflects what a sighted student gains from the image 
- Embedded directly with the image 

Do not: 
- Start with “image of,” “picture of,” or “graphic of” 
- Repeat caption text word‑for‑word 

## Accessible Descriptions
Complex Visuals → Use Alt Text + Accessible Description 
Use both when the image cannot be understood in one sentence. 

Examples include: 

- Charts 
- Diagrams 
- Images 
- Maps 
- Illustrations 

For more details about accessible descriptions, refer to `page-styles/accessible-description.md`

## HTML Links
Links should open in a new tab.  Include `target="_blank"` in the link html to make the link open in a new tab
Example:
<a href="http://phet.colorado.edu/en/simulation/gravity-and-orbits" target="_blank">
