# Image File Name

How to locate the image file that is connected to the figure html. 

Image files are located in `$ROOT/chapters/<NN>-<Chapter-Title-Slug>/images/`
The image file names begin with `<NN>.<SS>-figi-`
Where 
- `<NN>` is the chapter number
- `<SS>` is the section number
- `i` is the figure index
- Do **not** strip the leading 0 for single digit chapters or sections example the first figure in chapter 2 section three would be associated with a file that starts with `02.03-fig1-`

Find the appropriate image based on the first part of the file name.  This image is used for generated alternative text, figure caption text, and the accessible description.
