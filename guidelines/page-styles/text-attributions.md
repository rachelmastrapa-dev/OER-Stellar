# Style for Text Attributions

## Text Attribution Format

### Formatting Text Attributions

#### Guidelines for Attributions

all links open in new tab!!!

- These attributions will be used in an OER textbook, to credit the source of text that is being remixed from another textbook. Under a Creative Commons Attribution license

- If there is no link available for one of the parts of the attribution, do not create a link.

- For the Author information, treat it as a string, there are no changes needed for multiple authors.

- Some sections will have attributions to multiple chapters from one book or from separate books. If there are multiple Chapters and Chapter links, follow the instructions below in Multiple Chapters.

#### Text Format

This page was adapted from "Chapter Title[Chapter Link]" in Textbook Title[Textbook Link] originally written by Author[Author Link], and published under License[License Link].

#### Multiple Chapters

If there are multiple chapters, then number the Chapter Title and Chapter Link variables as Chapter Title1 and Chapter Link1, Chapter Title2 and Chapter Link 2, and so on until the last chapter and link, represented by Chapter TitleF and Chapter LinkF. In the multiple chapter text format below demonstrates the format if there are three total chapter titles. The multiple chapter example text demonstrates four total chapters in the attribution. The attribution should include all chapter titles formatted with commas up to the second to last chapter title. The final chapter title should have an and before it.
